# Proposal: reconcile-speckit-uf-refs

## Why

The five upstream Speckit command templates
(`speckit.specify.md`, `speckit.plan.md`, `speckit.tasks.md`,
`speckit.implement.md`, `speckit.constitution.md`) are missing
Unbound Force references that the rest of the command surface
relies on: Dewey knowledge-retrieval guidance
(`dewey_semantic_search` / `dewey_search`), constitution
awareness (`.specify/memory/constitution.md`), and — for the
implement phase only — `/uf.review-council`.

A red-first regression test,
`TestSpeckitTemplates_RequiredReferences`
(`internal/scaffold/scaffold_test.go:6727`), already asserts
the required-reference matrix against the durable injection
layer and fails RED today (tracked as issue #548). This change
implements the reconciliation edit (issue #549) that turns the
test green.

Per **ADR-002**
(`docs/decisions/002-uf-refs-source-of-truth-layer.md`,
Option B), the durable source-of-truth layer is **Step 6 of
`uf.init.md`**, not the standalone `speckit.*.md` files. Those
files are in `knownNonEmbeddedFiles`
(`scaffold_test.go:1242-1251`) and are regenerated by
`specify init` + `/uf.init`, so direct edits to them are
non-durable. Prerequisite #546 (the source-of-truth decision)
is CLOSED, resolved by ADR-002 (merged via #550).

## What Changes

- Inject the required-reference matrix into the three existing
  Step 6 guardrail blocks of `uf.init.md`:
  - **Spec-phase guardrails block** (covers `speckit.specify.md`,
    `speckit.plan.md`, `speckit.tasks.md`): add Dewey + constitution
    references.
  - **Implement guardrails block** (`speckit.implement.md`): add
    Dewey + constitution + `/uf.review-council`.
  - **Constitution guardrails block** (`speckit.constitution.md`):
    add Dewey + constitution references.
- Apply the edit to the canonical source
  `.opencode/commands/uf.init.md` and lockstep dual-write to the
  embedded asset
  `internal/scaffold/assets/opencode/commands/uf.init.md` so the
  drift test (`TestEmbeddedAssets_MatchSource`) stays green.
- Preserve the implement-only boundary: `/uf.review-council`
  MUST NOT appear in the spec-phase or constitution blocks.

This is a mechanical reference-injection edit — no per-file
block restructuring is required. The gating test keys on the
three existing block labels and is forward-compatible with the
shared spec-phase block.

## Capabilities

### New Capabilities
- None. This change adds reference strings to existing
  guardrail blocks; it introduces no new command or behavior.

### Modified Capabilities
- `uf.init Step 6 (Speckit Command Guardrails)`: the injected
  guardrail blocks now carry Dewey, constitution-awareness, and
  (implement-only) `/uf.review-council` references, so every
  `uf init` run durably propagates them into the five upstream
  speckit commands.

### Removed Capabilities
- None.

## Impact

- **Files edited**:
  - `.opencode/commands/uf.init.md` (Step 6 blocks)
  - `internal/scaffold/assets/opencode/commands/uf.init.md`
    (lockstep dual-write)
- **Tests turned green**:
  `TestSpeckitTemplates_RequiredReferences` (#548). Must remain
  green: `TestEmbeddedAssets_MatchSource`,
  `TestGuardrailTemplates_CommandSpecificContent`.
- **Downstream behavior**: every subsequent `uf init` injects
  the reconciled references into user speckit commands.
- **Co-merge constraint (design D5)**: this change and the #548
  test MUST land in the same PR. Merging the test alone would
  leave `main` red until this edit merges. The two remain
  separate issues (#548 test, #549 fix) but travel in one PR.
- **Branch**: implemented on `opsx/add-speckit-ref-assertion-test`
  (the #548 branch) to satisfy the co-merge constraint.

## Constitution Alignment

Assessed against the Unbound Force org constitution.

### I. Autonomous Collaboration

**Assessment**: PASS

The change edits a scaffold injection template only. Artifact
envelope formats and self-describing outputs are unaffected.
It strengthens cross-command consistency of the guardrail
artifacts that heroes consume.

### II. Composability First

**Assessment**: PASS

No new mandatory dependencies. The referenced tools (Dewey,
`/uf.review-council`) are referenced as guidance strings within
guardrail prose, not hard prerequisites — the speckit commands
remain usable standalone. Dewey guidance already documents a
Read/Grep/Glob fallback when Dewey is unavailable.

### III. Observable Quality

**Assessment**: PASS

The reconciliation is backed by an automated, reproducible
regression test (`TestSpeckitTemplates_RequiredReferences`)
that asserts the required-reference matrix and names the exact
file and missing reference on failure. No gatekeeping value is
modified; an existing gate is satisfied.

### IV. Testability

**Assessment**: PASS

The change is verified by a stdlib-only unit test that reads
the embedded asset via `assetContent` and asserts observable
content per file, in isolation, with no external services. The
red-first test proves the gate catches the absence of the
references before the fix lands.
